Frequently asked questions


    

      What is an .ics file?
      
An .ics file is the standard calendar format (RFC 5545) used to
      move events between calendars. Import it into Google Calendar, Outlook, Apple
      Calendar, or Thunderbird and the event appears in your calendar.

    


    

      Does ICS Generator upload my event data?
      
No. The page runs 100% in your browser — nothing you type ever leaves
      your device. Your events are saved in your browser's localStorage so they
      survive a reload; they are still never uploaded, and clearing the site's
      data removes them. The hosted site uses cookie-free
      Cloudflare Web Analytics
      to count visits (aggregate page views, referrers, and countries); your
      events and form data are never collected or sent anywhere.

    


    

      Can I create recurring events or reminders?
      
Yes — daily, weekly, monthly, and yearly recurrence, with optional
      day-of-week patterns, occurrence counts, and end dates, plus reminders
      set per event — minutes, hours, or days before the start — and all-day,
      timed, and multi-day events with attendees. In one .ics file each event
      carries its own reminder.
